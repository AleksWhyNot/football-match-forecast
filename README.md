# Вероятности исходов футбольных матчей

Нейросеть TensorFlow/Keras прогнозирует победу хозяев, ничью и победу гостей до начала матча. Используется архив Understat по пяти лигам за 2014/15–2019/20. Модель ежегодно обучается заново на всей завершённой истории.


Log loss 0.99187, Brier 0.59131, accuracy 51.4% на 1,725 матчах сезона 2019/20. Средняя ошибка суммы предматчевых ожиданий — 5.18 очка на команду, расчётного места — 1.96 позиции. В пределах двух мест оказались 68 из 98 команд. При выборе одного наиболее вероятного исхода модель не выбирает ничью ни в одном из 1725 матчей. Среди 345 встреч с наибольшей вероятностью ничьей таких результатов 104 (30.1%).
